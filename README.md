# Semana 02 — Tipos Primitivos en TypeScript (PM)

Programación Móvil · 3.° Bachillerato Técnico UETS (2026–2027).

Vas a resolver 2 retos (tipos primitivos, arrays y ficha UETS; estados móviles con unions y narrowing) y a grabar un screencast de 3 a 5 minutos explicando tu solución.

## Trabaja en Codespaces

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/UETS-Programacion-Movil/02-est-tipos-primitivos-pm)

1. Haz **Fork** de este repositorio a tu cuenta.
2. Abre tu fork con **Codespaces** (botón verde `<> Code` → pestaña `Codespaces` → `Create codespace on main`).
3. Instala dependencias: `pnpm install`.
4. Corre las pruebas: `pnpm test`.
5. Abre el **Pull Request desde Codespaces** contra `main` del repositorio oficial.

## Entrega

- **Video Screencast (3 a 5 min):** rostro visible en cámara, voz explicando tu solución y demo de `pnpm test` y `pnpm run check` en verde. Pega el enlace en la descripción de tu Pull Request.
- Checklist:
  - [ ] `pnpm test` pasa al 100 %.
  - [ ] `pnpm run check` sin errores.
  - [ ] Video con cámara y voz, enlace pegado en el PR.
  - [ ] No modificaste archivos de `tests/`.
